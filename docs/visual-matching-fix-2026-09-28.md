# 룩 수정·상품 사진 정합성 수정 기록

대상: LALA_Team. 기존 개발 서버를 재시작하거나 .env.local 값을 변경하지 않았다. 기존 미커밋 작업을 유지하고 요청 범위의 수정을 추가했다.

## 원인과 변경

- 하나만 변경: 모델의 전체 코디 응답을 그대로 적용하던 경로를 수정 범위가 제한된 패치로 바꿨다. 한 품목/색상만 변경, 다른 품목·속성 보존, 실제 적용된 변경만 답변한다. 변경이 없으면 이미지·상품·undo 이력을 유지한다.
- 공통 명세: 색상·무늬·소매·종류·바지 재질/형태·여밈·브랜드/모델을 품목별로 기록한다. 이미지 생성 응답의 보강 명세와 사진 관찰 결과를 UI, 저장 기록, 상품 검색, 수정에 전달한다. 기존 이미지의 색은 전역 팔레트로 추정하지 않는다.
- 실제 이미지 확인: 기존 NVIDIA 비전 15초 실패 경로를 GPT-5.4 mini 이미지 입력으로 교체했다. 품목별 사진 관찰과 판매처 상품 사진 비교를 분리한다. 사진에서 확인되지 않는 속성은 미확인으로 남긴다. 수정 단계는 저장된 관찰 결과를 재사용한다.
- 불일치 제외: 무지/카모·긴팔/민소매·버건디/검정·회색/흰색·치노/트랙·데님/스웨트·버튼 셔츠/하프집업 니트를 구별한다. 베스트/조끼를 독립 아우터로 처리한다. 액세서리는 제외한다.
- 개별 상품: 실제 판매처 상세페이지와 사진을 확인한다. 검색 결과 페이지를 상품으로 표시하지 않는다. 누락 품목은 별도 검색하며, 이미 거절된 주소는 재사용하지 않는다. 재검색에서 불일치로 확인된 과거 상품도 제거한다.
- 동시 검색: 카드별 상태를 유지하고 판매처 fetch 동시성은 3개, 호스트별 시작 간격은 250ms로 제한한다. HTTP429의 Retry-After에 따라 대기하고 다른 판매처를 탐색한다. 서버 검색 110초, 내부 경로 120초, 화면 130초 제한과 취소를 둔다.

## 검증

- 회귀 테스트: 한 품목 수정, 품목별 명세 유지, 패턴·색·소매·종류 불일치, 조끼 포함, 과거 잘못된 상품 제거, 시간 제한, 동시 결과·기록 복원을 포함한다.
- 오프라인 브라우저: 5개 동시 요청의 역순 완료, 지연·취소·재시도, 수정·되돌리기·history 복원, no-op 유지, 실제 이미지/설계명세/관찰명세 전달, 모바일·데스크톱 표시를 확인했다.
- 실제 NVIDIA 수정 API: 합성 명세에서 상의 색상 한 곳만 변경, 다른 품목·속성 보존을 확인했다. 성공 사례 약9.3초. 이 검사에서 이미지 생성은 모의 처리했다.
- 실제 이미지 생성: 버건디 긴팔 니트·카키 무지 카고·그레이 뉴발란스574·네이비 경량 조끼를 생성하고 사진 검사를 통과했다. 약27.4초. 생성 이미지도 직접 확인했다.
- 실제 상품 검색: 기존 합성 룩북으로 반복 검증했다. 마지막 실행 약30초, 4개 중 티셔츠·카고2개가 상품 사진 비교를 통과했고 신발·재킷2개는 미확인이었다. 직전 실행에서는 카고·신발·재킷3개가 통과했다. 따라서 모든 실행에서4개 상품을 확보했다고 주장하지 않는다.

## 남는 한계

실시간 검색 결과와 판매처 차단/판매 상태에 따라 일부 품목은 계속 비어 있을 수 있다. API 모델의 사진 판단도 완벽한 정답이 아니다. 확인 실패 시 룩북과 찾은 상품을 유지하며, 미확인 후보에 사진 일치 표시를 붙이지 않는다. 사진 비교 완료는 같은 SKU, 소재 성분, 실제 착용 핏까지 검증했다는 뜻이 아니다.

공개 데이터셋은 조사·평가했으며 다운로드/모델 학습은 수행하지 않았다. 별도 보고서: fashion-dataset-evaluation.md.
