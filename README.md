# Fashion Planning Agent

한 줄의 아이디어/키워드만으로 트렌드 조사 → 컨셉 기획 → 룩북 이미지 → 대략적인 원가/판매가까지, 몇 분 안에 **초안**을 잡아주는 에이전트입니다.

## 포지셔닝

**"정밀 원가 계산 툴"이 아니라 "초안 잡기 + 감(感) 잡기 도구"** 입니다.

- **타겟**: 테크팩도, 소싱팀도 없는 1인/소규모 신진 디자이너 (무신사 스튜디오·동대문 기반 셀러 등)
- **가치**: 아이디어 단계에서 트렌드 근거가 있는 컨셉과 대략적인 원가 감을 빠르게 잡는 것. 실제 공급업체 견적을 대체하지 않습니다 — 원가/마진 수치는 웹검색 기반 LLM 추정치이며, 실제 발주 전에는 반드시 실제 원단 시세를 따로 확인해야 합니다.
- **의도적으로 안 하는 것**: 유저 검색/탐색 기능, 실제 원단 공급업체 DB 연동, 정밀 원가 계산 — 이 셋은 이미 시장에 있는 엔터프라이즈 툴(예: MannyAI)이나 정부 지원 툴(TEX-AI)의 영역이라 정면 경쟁하지 않습니다.

## 스택

- Next.js (App Router, TypeScript) — 프론트엔드 + API 라우트 통합
- OpenAI
  - `gpt-4o` (Responses API + `web_search_preview`): 트렌드 조사, 원가/마진 조사
  - `gpt-4o` (Chat Completions, JSON mode): 컨셉 기획, 원가 추정, 시즌/소재 모순 체크, 이미지 정합성 검증(vision)
  - `gpt-image-1` (`images.generate`): 룩북 이미지 생성
- Spline: 히어로 3D 배경

## 시작하기

```bash
cp .env.example .env
# .env에 OPENAI_API_KEY 채워넣기
npm install
npm run dev
```

http://localhost:3000 에서 확인.

## 파이프라인

1. **Trend** — 키워드에서 계절/지역을 파악해 하이퍼로컬 트렌드 + 실제 기후 데이터를 웹검색으로 조사
2. **Concept** — 트렌드를 바탕으로 컨셉/원단 기획, 시즌-소재 모순 자가 체크·수정
3. **Lookbook** — 컨셉 기반 룩북 이미지 생성, Vision으로 색상/원단/타겟 고객(성별·연령대) 일치 검증 후 불일치 시 1회 재생성
4. **Cost** — 원단 실시세/마진율 웹검색 → 원가 추정(합산은 코드로 검산) → 마진 기준 미달 시 대체 원단 비교 후 재평가(최대 3회), 회차별 변화를 차트로 시각화

## 자가검증 루프

세 곳에 "생성 → 검증 → 실패 시 수정" 루프가 있습니다 (모두 재시도 횟수 상한 있음):

- **Vision-Text 정합성**: 룩북 이미지가 스펙과 맞는지 재확인
- **원가 자가재평가**: 마진율이 목표(65%) 미달이면 대체 원단 탐색 후 재계산
- **시즌/소재 모순 체크**: 계절과 원단이 명백히 안 맞으면 자동 수정

터미널(`npm run dev` 실행 창)에서 각 단계가 어떤 API/모델을 호출하는지 실시간 로그로 확인 가능합니다.
